# MOONLAB Stock

**เว็บที่ใช้งานจริง:** https://moonlab-base.moonlab-jewelry.workers.dev

ระบบจัดการสต็อก ต้นทุน และกำไรของร้าน Moonlab — เว็บแอปที่ใช้งานหลักบนไอโฟน/ไอแพด
ข้อมูลถูกเก็บบนฐานข้อมูลกลาง เจ้าของร้านทั้งสองคนจึงเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์

## ใช้ทำอะไรได้

- **ภาพรวม** — กำไรสุทธิรายวัน ยอดขาย มาร์จิ้น ต้นทุนรวม ค่าโฆษณา
- **บันทึกขาย** — ตัดสต็อกและคำนวณกำไรสุทธิให้อัตโนมัติ (หักค่าแพค ค่าส่ง ค่าธรรมเนียมช่องทาง)
- **นำเข้าออเดอร์** — อ่านใบปะหน้า TikTok Seller (PDF) และไฟล์ Excel แล้วจับคู่สินค้าให้เอง
- **สต็อกสินค้า / แพคเกจ / ต้นทุน** — ดูของใกล้หมด คำนวณต้นทุนแพคตามประเภทสินค้า
- **วางแผนสั่งของ** — คำนวณจากยอดขายจริงย้อนหลัง
- **บัญชี** — รายรับรายจ่ายแยกตามกระเป๋าเงิน พร้อมโอนระหว่างกระเป๋า

## โครงสร้าง

เว็บแบบ static ล้วน ไม่มีเซิร์ฟเวอร์ของตัวเอง — ข้อมูลคุยกับ Supabase ผ่านฟังก์ชันที่ตรวจรหัสลับ

| ไฟล์ | หน้าที่ |
|---|---|
| `MOONLAB Stock.dc.html` | ตัวแอปทั้งหมด — แก้ที่ไฟล์นี้ไฟล์เดียว |
| `cloud.js` | ซิงก์ข้อมูลข้ามเครื่อง: merge เมื่อแก้พร้อมกัน, เข้าคิวเมื่อออฟไลน์ |
| `supabase-setup.sql` | สร้างตาราง + ล็อก RLS ให้เข้าถึงได้เฉพาะผ่านฟังก์ชันที่มี token |
| `build.sh` | Cloudflare รันตอน deploy สร้าง `config.js` จาก environment variables |
| `build.ps1` / `serve.ps1` | build และทดสอบบนเครื่อง Windows (ไม่ต้องใช้ Node/Python) |
| `sw.js` `pwa.js` `manifest.webmanifest` | ทำให้ติดตั้งบนหน้าจอโฮมและใช้ตอนออฟไลน์ได้ |

## วิธีติดตั้งและ deploy

ดู **[DEPLOY.md](DEPLOY.md)** — มีขั้นตอนทีละคลิกครบตั้งแต่สร้างฐานข้อมูลจนขึ้นเว็บ

## ความปลอดภัย

repo นี้เป็น public — **รหัสลับทั้งหมดอยู่นอก git**

- `config.js` (ไฟล์ที่มีรหัสจริง) ถูกกันไว้ใน `.gitignore`
- ตอน deploy Cloudflare สร้างไฟล์นี้ขึ้นเองจาก environment variables ที่เก็บไว้ฝั่งมัน
- ฐานข้อมูลปิดการเข้าถึงตารางโดยตรงทั้งหมด เปิดเฉพาะ 4 ฟังก์ชันที่ต้องส่ง token ถูกต้อง
